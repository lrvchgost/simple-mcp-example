## Описание проекта
Ты разработчик mcp серверов

Используй @modelcontextprotocol/sdk для разработки

Используй typescript последнюю стабильную версию
Используй версию Node.js последнюю стабильную

Заметки хранятся в локальных файлах в папке notes, если ее нет, создай в текущем каталоге пользователя (cwd)

Сделай защиту от note_name/pattern от path traversal (../, абсолютные пути) 

Используй stdio как транспортный уровень

Есть тулы
- add_note
	- note_name
		- параметр: (строка) имя файла для заметки (required)
		- описание: имя файла в который будет сохранена заметка, расширение .md добавляется к имени файла
	- text
		- параметр: (строка) текст для сохранения в заметку (required)
		- описание: текст, который хочется сохранить в заметку, можно передать явно или можно попросить модель сделать саммари, выжимку или взять последние идеи и сохранить в заметку
- get_all_notes 
		- описание: выводит список имен всех заметок, сортировка по дате (mtime файла) от старых к новым
- view_note_content
	- note_name
		- параметр: (строка) имя заметки (required)
		- описание: возвращает текст заметки
- search_notes
	- pattern
		- параметр: (строка) паттерн (регистронезависимый) для поиска в названиях файлов (required)
		- описание: возвращает список файлов, в именах которых есть искомый паттерн
- search_in_files
	- pattern
		- параметр: (строка) паттерн для поиска в содержимом файлов (required)
		- описание: возвращает список файлов, поиск регистронезависимый, в содержимом которых есть искомый паттерн, выводит в формате
			- автор
			- дата и время
			- строку, в которой найден паттерн, плюс ±2 строки вверх и вниз от найденной строки

Допустимые расширения файлов
.md


Модель заметки (данные заметки хранятся в файле)
- дата и время
- автор (бери пользователя из операционной системы $USER)
- текст заметки

Формат заметки (структура файла .md, каждая строка отдельно)
```
Автор: <$USER>
Дата: dd.mm.yyyy HH:mm
<пустая строка>
<текст заметки>
```

Для каждого тула реализация должна быть в отдельной папке с именем тула, в файле протокола только подключение src/tools/<name>/index.ts

Для тестов используй jest, тест лежит рядом с файлом тула

Запуск MCP-сервера: сервер запускается как stdio-процесс (команда `node <собранный входной файл>`, по умолчанию `build/index.js`); HTTP-сервер не используется
